# Fairy AE Demo

Vue + Vite implementation inspired by the supplied Fairy dynamic-effects reference.

## Features

- Dark blue sci-fi visual-novel presentation
- Animated layered orbital emblem made with CSS
- Changeable dialogue scenes
- Play/pause, seek bar, mute, menu and next controls
- Responsive layout for desktop and mobile

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
